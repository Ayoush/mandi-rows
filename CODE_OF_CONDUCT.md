# Contributor Covenant Code of Conduct

We pledge to make participation in our community a harassment-free experience for everyone. We expect respectful, constructive behavior from all contributors.

Unacceptable behavior includes harassment, personal attacks, and publishing others' private information. Report violations via GitHub Issues or the Intervues community channel.

Adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
